# E-01  Domain `projects`

```text
E-01  Domain `projects`
Depends on:     M0 (walking skeleton)
Status:         Proposed
```

**Scope.** Screens 0 All projects and 1 Wish and AI: create, list, open, rename, delete projects; links and files; agent harness and Claude model; the session API key (test call, never stored); optional GitHub sign-in of the project starter; the project brief. Out: questions (E-02), anything of a run.

**Sources.** screens 0, 1 (skill `screen-build`); `software-elements.md` 3.0, 3.1; BPMN level 1: Receive wish, Check API key, Key valid?, Key rejected, Create project (skill `bpmn-model`); FR-PRJ, FR-AI, FR-STK-08, FR-AGT-04; ADR-033, ADR-034, ADR-035.

**Risks.** Key handling must never write a key or token anywhere (QR-SEC-01); GITHUB_OAUTH_CLIENT_ID missing hides the GitHub card.
