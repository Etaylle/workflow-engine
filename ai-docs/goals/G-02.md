# G-02  MVP business requirements

```text
G-02  MVP business requirements
Outcome:        A client goes from a wish to a confirmed contract and, on Run, to a generated, tested project
                (ZIP, optional public GitHub repository, optional Deploy to Render link) without editing a
                technical file (business goal G1, G3).
Measure:        All MUST requirements of requirements.md 4 to 9 are Done and traced to passing tests; the acceptance
                scenarios of requirements.md 11.1 pass end to end; a reference run of the canteen wish finishes
                within about 4 hours after Run (G2, ADR-039 reopen trigger).
Epics:          E-01 projects, E-02 questions, E-03 documents, E-04 workflows, E-05 settings, E-06 execution,
                E-07 case "From wish to result"
Requirements:   FR-PRJ, FR-AI, FR-Q, FR-STK, FR-WF, FR-CON, FR-DOC, FR-EXE, FR-TIME, FR-RES, FR-STAT, FR-STOP,
                FR-EXP, FR-SET, FR-AGT; QR (6); IR (8); data (9)
Priority:       MUST
Status:         Proposed (starts when G-01 is closed, WFL-070)
```

## Order of the epics

Domain epics in the order of the dependency matrix (WFL-101) and of `ai-docs/README.md` 5: `projects` → `questions` → `documents` → `workflows`; `settings` alongside `workflows` (screens 6 and 7 feed the contract of screen 8); `execution` last; then the case epic that connects them (WFL-104).

Each domain epic follows the chain of `ai-docs/software-elements.md` 1 (screen element → Svelte component → API operation → use case → domain record → table, plus the AI agent that writes it), uses the skill `screen-build` for its screens and `bpmn-model` for states.

## Rules that hold for every epic of this goal

- No login, no roles, no secret store (WFL-120, ADR-034); keys and tokens in session memory only (ADR-033, ADR-035).
- Claude only (ADR-032); every AI result validated against its JSON schema with one retry (FR-AGT-03).
- Every visible text from the translation resource, English and German (`i18n.md`); every screen state designed (`ux-ui.md`).
- Before an epic becomes Ready: `requirements.md` covers the features of `software-elements.md` 0.2 that the epic builds (open point in `ai-docs/README.md` 6), (the conflict of FR-EXE-04, FR-EXE-07, FR-EXE-08 with ADR-038 and ADR-039 was resolved in `requirements.md` 0.4, D-06).
