What happens after Run

  1. A build space is created on the engine from the prepared Java + Svelte setup.
  2. An AI team runs 16 steps per task: a development supervisor plans it, the team defines, builds, tests and reviews it with continuous integration, and the supervisor sums it up.
  3. If the team cannot fix a problem, the run pauses and asks you one short question.
  4. A finished task turns green, is saved and is pushed to the public GitHub repository.
  5. You can stop at any time and download what is finished.
